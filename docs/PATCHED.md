# Patched bindings

The bindings are generated by [runic](https://github.com/Samudevv/runic) from the C headers.
Regenerating overwrites hand fixes, so each is also pinned by a typed variable in the
package's `patched.odin`: a regeneration that drops a patch fails to compile there instead
of misbehaving at run time.

To regenerate, run `make generate`, re-apply every row below, and build the package.

## Generation rules

`scripts/postprocess.sh gexiv2` applies these to `gexiv2/gexiv2.odin` after runic. They are
odin-gtk's rules as odin-glib keeps them, trimmed to what runic 0.8 produces from the gexiv2
headers. Each is pinned in `gexiv2/patched.odin`.

| rule | reason |
|---|---|
| `^glib.char` becomes `cstring` | `gchar *` is a typedef'd char pointer, which runic leaves as a pointer to `char` |
| `^PreviewProperties` (`props` of `metadata_get_preview_image` and `metadata_try_get_preview_image`) | the header passes one `GExiv2PreviewProperties *`, and `to.detect.parameters: declared` in `gexiv2/rune.yml` makes it `^T` where runic 0.8 wrote `[^]` for a name ending in "s". `values` of `metadata_set_tag_multiple` and `metadata_try_set_tag_multiple` (`const gchar **`, NULL-terminated) is an array: it is the whole `arrays:` list, so it stays `[^]cstring`. `scripts/check-generated.sh` holds the list | `patched_metadata_get_preview_image` |
| `Foo :: _GExiv2Foo` is deleted and `_GExiv2Foo` becomes `Foo` | one name per struct |
| `TYPE_*` macros become procedures returning `*_get_type()` | macro text runic quotes as a string |
| `XmpFormatFlags` (`gexiv2_flags` in `postprocess.sh`) becomes `XmpFormatFlagsBit :: enum u32` of bit indices plus `XmpFormatFlags :: bit_set[XmpFormatFlagsBit; u32]` | `{.OMIT_PACKET_WRAPPER, .USE_COMPACT_FORMAT}` instead of integer ORs; the size and bits are those of C; see DECISIONS §4 |

Nothing is written by hand.

## Generation settings

`scripts/generate.sh` links `build/inc/gexiv2` to `/usr/include/gexiv2`, so the rune file
reaches `<gexiv2/...>` without putting `/usr/include` on the include path. With the real libc
headers on the path, runic emits the `errno` constants and libc types into the package.
